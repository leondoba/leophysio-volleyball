# Volley Physio · LeoPhysio (application Android)

1. Créez un NOUVEAU dépôt GitHub (par exemple `leophysio-volleyball`).
2. Envoyez-y tout le contenu de ce dossier (Add file > Upload files), puis créez à la main le fichier
   `.github/workflows/build-apk.yml` avec le contenu fourni (le dossier `.github` est souvent masqué à l'envoi).
3. Onglet Actions : attendez la pastille verte, téléchargez « LeoPhysio-Triple-saut-APK » (c'est l'APK de cette application),
   décompressez, installez `app-debug.apk`.
L'application s'installe à côté de l'ancienne (identifiant différent : com.leophysio.volleyball).
